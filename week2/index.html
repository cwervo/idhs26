Digital Activity: ArUco Tracking

In groups, we will take a premade ArUco tracking web script and modify the HTML in response to the presence, position, or tilt of the markers.

  • Download the base script: ArUco Web Starter Kit
  • Challenge: Map specific digital actions (e.g., color changes, DOM element toggles) to different tag IDs or spatial movements.
