Technical Setup

Before we break into groups, everyone needs to set up their Python environment to talk to our Rongta RP326 printers.

Step 1: Install Python Libraries

Open your terminal and install the required packages for computer vision, image processing, and printer communication:

pip install opencv-python pillow python-escpos
Step 2: Find Your USB Vendor & Product IDs

To let Python talk to the printer, you need its exact hardware address.

  • Mac: Click the Apple Logo > About This Mac > System Report > USB. Find the printer and look for the Vendor ID and Product ID (usually looks like 0x04b8).
  • Windows: Open Device Manager > Universal Serial Bus controllers > Right-click the printer > Properties > Details > Hardware Ids.

Group Activity: The 1-Bit Photobooth

We are breaking up into 3 groups. We will pair program using the starter code below to build a functional hardware photobooth, and then each group will modify the code to create a unique experience.

Starter Code: The 1-Bit Thermal Photobooth

Copy this code into a file named photobooth.py. Remember to change the VENDOR_ID and PRODUCT_ID!

import cv2
from PIL import Image
from escpos.printer import Usb

# ==========================================
# 1. SETUP THE PRINTER
# ==========================================
# Students: Replace 0xXXXX with your specific Vendor and Product IDs!
VENDOR_ID = 0x04b8  # Example ID, needs to be updated
PRODUCT_ID = 0x0202 # Example ID, needs to be updated

try:
    print("Connecting to Rongta RP326...")
    p = Usb(idVendor=VENDOR_ID, idProduct=PRODUCT_ID, profile="RP326")
    print("Printer connected successfully!")
except Exception as e:
    print(f"Printer connection failed: {e}")
    print("Check your USB IDs and make sure the printer is turned on!")
    exit()

# ==========================================
# 2. SETUP THE WEBCAM
# ==========================================
# '0' is usually the default built-in laptop webcam. 
cap = cv2.VideoCapture(0)

print("Webcam active. Press SPACEBAR to print a photo. Press ESC to quit.")

while True:
    ret, frame = cap.read()
    if not ret:
        print("Failed to grab frame from camera.")
        break

    cv2.imshow("Thermal Photobooth - Press SPACE to print!", frame)
    key = cv2.waitKey(1) & 0xFF

    # ==========================================
    # 3. THE PRINT LOGIC (Triggered by Spacebar)
    # ==========================================
    if key == 32:  # ASCII code for Spacebar
        print("SNAP! Processing image...")
        
        rgb_frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
        pil_img = Image.fromarray(rgb_frame)
        
        # --- IMAGE PROCESSING FOR THERMAL PRINTERS ---
        # 80mm receipt paper is exactly 512 pixels wide. 
        target_width = 512
        width_percent = (target_width / float(pil_img.size[0]))
        target_height = int((float(pil_img.size[1]) * float(width_percent)))
        
        resized_img = pil_img.resize((target_width, target_height), Image.Resampling.LANCZOS)
        
        # Convert to 1-bit monochrome (pure black and white) with dithering
        dithered_img = resized_img.convert('1')
        dithered_img.save("last_photo.jpg")
        
        # Send to printer
        print("Printing...")
        p.image("last_photo.jpg")
        p.text("\n--- Thanks for stopping by! ---\n\n\n")
        p.cut()
        print("Done! Ready for the next one.")

    # ==========================================
    # 4. QUIT LOGIC (Triggered by ESC)
    # ==========================================
    elif key == 27:
        print("Closing photobooth...")
        break

cap.release()
cv2.destroyAllWindows()

Prototyping Prompts

Once your group gets the base script printing, pick one of the following prompts to iterate on:

  • Group 1: The Information Receipt
    Combine the photobooth experience with one (or a mix!) of your ideas from the receipt homework assignment. Can you incorporate borders, text decorations, or special formatting to make the visual hierarchy more clear in such a small space?
  • Group 2: The Analog Glitch Art Generator
    Break the dithering! Intercept the image using OpenCV before it goes to the printer. Crank the contrast, apply edge-detection filters (like Canny), or slice and mirror the image array to create thermal glitch art.
  • Group 3: The ASCII Text Mirror
    Abandon the p.image() function. Break the webcam frame down into a tiny grid, calculate the average brightness of each "block", and map that brightness to a specific ASCII character (e.g., # for dark, . for light). Print a portrait entirely out of text characters!
